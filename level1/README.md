

# 🚀 **Next.js Level 1 – Introduction & Setup**

---

## 🔹 1. Why use Next.js over React?

👉 **React (CRA)** vs **Next.js**

* React me:

  * Client-side rendering (CSR)
  * SEO weak(Search Engine Optimization)
  * Routing manually setup

* Next.js me:

  * ✅ Server-side rendering (SSR)
  * ✅ Better SEO
  * ✅ Built-in routing
  * ✅ Fast performance
  * ✅ API routes support (backend bhi bana sakte ho)

👉 **Conclusion:**
Next.js = React + extra powerful features

---

## 🔹 2. Project kaise banaye (Create Project Command)

```bash
npx create-next-app@latest
```

👉 Ye command:

* New Next.js project create karta hai
* Setup automatically karta hai

---

## 🔹 3. Project run kaise kare

Step 1:

```bash
cd project-name
```

Step 2:

```bash
npm run dev
```

👉 Browser me open:

```
http://localhost:3000
```

---

## 🔹 4. Node modules install karna

```bash
npm install
```

👉 Ye command:

* `node_modules` folder install karta hai
* Dependencies download karta hai
